## Pre-decided design (do not relitigate; escalate if you believe it is wrong)

**Slice:** id `LLM` (already exists), name stays "LLM Enrichment". All nine files move
from `VitaTrack.Core/Services` + `VitaTrack.Core/Models` into
`VitaTrack.Core/Features/LlmEnrichment/`. This is a PURE namespace move — no new
abstractions, no pattern work, no behavior change. The slice is a provider/infrastructure
slice (no controller, no views, no tables).

**File moves** (git mv, then namespace `VitaTrack.Core.Features.LlmEnrichment`):
- `VitaTrack.Core/Services/ILlmService.cs`           → `VitaTrack.Core/Features/LlmEnrichment/`
- `VitaTrack.Core/Services/LlmService.cs`            → `VitaTrack.Core/Features/LlmEnrichment/`
- `VitaTrack.Core/Services/ILlmClient.cs`            → `VitaTrack.Core/Features/LlmEnrichment/`
- `VitaTrack.Core/Services/LlmClient.cs`             → `VitaTrack.Core/Features/LlmEnrichment/`
- `VitaTrack.Core/Services/ISupplementLabelParser.cs` → `VitaTrack.Core/Features/LlmEnrichment/`
- `VitaTrack.Core/Services/SupplementLabelParser.cs`  → `VitaTrack.Core/Features/LlmEnrichment/`
- `VitaTrack.Core/Services/IHtmlScraperService.cs`    → `VitaTrack.Core/Features/LlmEnrichment/`
- `VitaTrack.Core/Services/HtmlScraperService.cs`     → `VitaTrack.Core/Features/LlmEnrichment/`
- `VitaTrack.Core/Services/UrlSafetyValidator.cs`     → `VitaTrack.Core/Features/LlmEnrichment/`
- `VitaTrack.Core/Models/LlmResult.cs`                → `VitaTrack.Core/Features/LlmEnrichment/`

Consumers: `VitaTrack.Core/ServiceCollectionExtensions.cs` (registrations + named
`llm` HttpClient), the Supplements slice (`SupplementController`, `ImportSupplementsHandler`)
and every LLM test class. Add `using VitaTrack.Core.Features.LlmEnrichment;` where the
compiler demands; keep existing `using VitaTrack.Core.Services;` lines that still
resolve to remaining services (`CsvImportService` left Services in the MS conversion —
check each file; remove nothing blindly, `dotnet format` will not strip unused usings).

**No behavior changes of any kind.** No interface renames, no method moves, no config
changes. `VitaTrackOptions` stays in its allowlisted home.

**OUT OF SCOPE (explicitly deferred):** anything about the OpenAI-compatible API shape,
prompt content, parser rules, or `VitaTrackOptions` structure; Supplements-slice changes
beyond namespace usings; any test edit beyond `using` lines; any e2e change
(`supplement-llm-integration.spec.js` self-skips without an API key — leave it alone).
